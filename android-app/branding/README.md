# Approved App Branding

- `logo-source.png`: the user's full gold-on-green artwork, unchanged.
- `logo-transparent-deep-green.png`: transparent deep blue-green variant; only use where a background-free emblem is needed. Do not use a gold transparent variant.

The Android launcher, splash and Play graphics use the original full artwork. `tools/export_logo.py` only sizes it for the required formats and icon masks.

The transparent variant was made with the built-in image generation tool. Prompt: preserve the complete Arabic calligraphy, minaret and ornaments; remove the background; recolor the gold relief deep emerald (`#0F3D30`) with restrained green highlights; no gold or additional text. The original artwork is retained separately.
